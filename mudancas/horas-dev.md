# Registro de horas da equipe de desenvolvimento

Use uma linha por pessoa, data e atividade. Uma mesma entrega pode ter várias
linhas, inclusive quando duas pessoas trabalham juntas. O vínculo com o
[changelog](CHANGELOG.md) permite relacionar o esforço às mudanças entregues.

## Como preencher

- Informe tempo efetivamente trabalhado, incluindo implementação, revisão,
  testes e documentação. Não use o intervalo entre commits como duração.
- Use horas decimais: 30 minutos = 0,50 h; 1h30 = 1,50 h. Desconte pausas.
- Em trabalho em dupla de uma hora, cada pessoa registra 1,00 h: são 2,00
  horas-pessoa. Evite registrar duas vezes o mesmo período para a mesma pessoa.
- Inclua a entrega/etapa com o mesmo nome usado no changelog e descreva a
  contribuição individual. Acrescente commit ou PR quando disponível.
- Tempos desconhecidos ficam como **A preencher**, nunca como zero. Cada
  participante confirma seus lançamentos; estimativas não entram no total realizado.
- Atualize o resumo manualmente ao adicionar ou corrigir um lançamento.
  Esta tabela Markdown não calcula totais automaticamente.
